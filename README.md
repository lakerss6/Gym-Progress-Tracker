## About the app

Gym Progress Tracker will make it easier to keep a record of gym sessions and see how training changes over time. Users will be able to log exercises, sets, reps, and weights, review previous workouts, and follow their progress toward strength goals.

Development is starting with the React frontend, one component at a time. A backend will be added later to support user accounts and save workout history across devices.

## Current progress

The project is in early development. The first header component includes:

- The app title
- A short description
- A **Log Workout** button

The button is visual only for now. The React app setup, styling, and workout logging functionality are still to come.
